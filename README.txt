WAREHOUSE AI SHOWCASE – SETUP

1. Place these MP4 files inside the videos folder:
- Automated Monthly Report.mp4
- Excel VBA Data Extraction.mp4
- How AI Eliminates Wasted Warehouse Crane Movements.mp4
- MHEinspect AI coded App.mp4

2. Create a public GitHub repository, for example: warehouse-ai-showcase

3. Upload index.html and the videos folder.

4. Open Settings > Pages, then choose:
- Source: Deploy from a branch
- Branch: main
- Folder: /root

5. Your page will normally be available at:
https://YOUR-GITHUB-USERNAME.github.io/warehouse-ai-showcase/

IMPORTANT:
GitHub normally rejects individual files above 100 MB. Compress large videos before uploading.
Recommended export: MP4, H.264, 720p or 1080p, 30 fps.

After the page works, create a new QR code pointing to the GitHub Pages address.
